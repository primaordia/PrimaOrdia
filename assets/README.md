# Game Art Slots

Place future graphics here using simple lowercase names:

- `heroes/leela.png`
- `heroes/leela-face.png`
- `heroes/feenix.png`
- `heroes/feenix-face.png`
- `heroes/poliana.png`
- `heroes/poliana-face.png`
- `enemies/grub-raider.*`
- `enemies/stone-brute.*`
- `enemies/hex-imp.*`
- `environment/trees.*`
- `environment/core.*`

Leela, Feenix, and Poliana are currently used as HUD portraits and face textures on procedural 3D battlefield models. The remaining slots are ready for later sprite sheets, portraits, textures, or 3D model files.
